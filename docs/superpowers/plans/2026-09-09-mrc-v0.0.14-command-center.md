# MRC v0.0.14 Command Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a trustworthy native MRC command center with working START/STOP/RESTART controls, responsive runner cards, richer terminal commands, and no regression of v0.0.13 safety.

**Architecture:** Keep lifecycle authority in MRC.Core and make every GUI/bulk action delegate to it. Improve Windows ownership evidence with a non-handle parent-PID enumeration fallback, add a verified Restart core operation, then replace the table-centric WPF shell with responsive cards. CLI presentation remains centralized and segmented.

**Tech Stack:** .NET / C#, WPF, Windows native process APIs, GitHub Actions, PowerShell verification scripts.

**Spec:** `docs/superpowers/specs/2026-09-09-mrc-v0.0.14-command-center-design.md`

## Global Constraints
- Work only on `precert-v0.0.14`; do not mutate published v0.0.13 evidence.
- All runner mutation remains constrained to the authorized machine/root and discovered configured managed runners.
- External/system runners have zero control path.
- Genuinely unattributed process ownership remains fail-closed before START.
- BUSY normal stop/restart remains protected; force stop remains explicit/confirmed.
- Normal stop must verify actual exit before OFF.
- Restart must complete verified STOP -> OFF before START.
- 20 FPS shared animation architecture remains one shared GUI animation timer.
- Every task uses RED -> correct-failure proof -> minimal GREEN -> regression.
- Final acceptance requires fresh 2048x1222, 1200x760, 1180x760, 900x560 previews and live Main-PC proof.
