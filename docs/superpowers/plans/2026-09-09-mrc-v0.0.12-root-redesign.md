# MRC v0.0.12 Root Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Owner-approved 90-item MRC v0.0.12 root redesign while preserving all existing safety, BUSY-protection, update-integrity, and machine/root fences.

**Architecture:** Preserve the proven `MRC.Core` control/update engine where semantics are already correct, but insert explicit runtime ownership classification, diagnostics/repair, release-stage metadata, semantic CLI rendering, single-instance activation, and a rebuilt terminal-style WPF shell. Use one dedicated redesign acceptance harness and branch CI workflow to prove each subsystem independently, then run the legacy PASS1–4 regression harnesses and deterministic WPF preview rendering.

**Tech Stack:** .NET 10, C#, WPF, PowerShell, GitHub Actions (`windows-latest`), existing custom executable test harness pattern.

**Spec:** `docs/superpowers/specs/2026-09-09-mrc-v0.0.12-root-redesign-design.md`

## Global Constraints

- Authorized OS machine identity is exactly `DOONCHYSCOMPUTI`.
- Authorized managed-runner root is exactly `D:\Git_Runners_Main`.
- External and unattributed runner processes are never controllable.
- No Administrator requirement by default.
- BUSY runners cannot be stopped through normal OFF or TURN ALL OFF.
- BUSY force-stop requires explicit confirmation.
- Closing MRC never stops runners.
- Existing SHA-256 verification, package validation, atomic activation, launch verification, and rollback retention remain mandatory.
- GUI runtime states remain exactly `OFF`, `STARTING`, `IDLE`, `BUSY`, `STOPPING`, `ERROR`.
- `/ - \\ |` remains the canonical spinner sequence with one shared animation clock.
- Any applicable certification category below 10.0/10 means HOLD.
