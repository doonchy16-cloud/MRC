# MRC v0.0.13 Root Repairs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver MRC v0.0.13 with root-correct global control lifecycle, truthful managed/external state, safe restart behavior, semantic CLI/help output, read-only update checking, true 20 Hz animation, and materially improved GUI readability.

**Architecture:** Repair runtime truth at `MRC.Core` boundaries first, then layer presentation improvements on top. Individual and bulk controls remain thin callers over one shared control lifecycle. Unknown process evidence remains separate system evidence unless it can be associated to a managed runner. Normal stop must prefer graceful GitHub-runner shutdown semantics and verify lifecycle completion before a later start is treated as safe.

**Tech Stack:** .NET 10, C#, WPF, Windows process APIs, GitHub Actions self-hosted runner semantics, existing custom test harnesses and PowerShell verification scripts.

**Spec:** `Auth/0013_V13FX.md` plus all non-conflicting prior authority files.

- Branch: `precert-v0.0.13`; never implement on `main`/`master`.
- Expected live managed fixture: TOTAL 7 / IDLE 3 / BUSY 0 / OFF 4 / ERROR 0 / TRANSITION 0.
- No symptom patches, runner-name exceptions, or UI suppression.
- Preserve machine/root fence, exact-path ownership, BUSY protection, force-stop confirmation, Doctor risk classification, Diagnose read-only behavior, updater SHA/manifest/rollback safety, and external-runner non-control.
- Shared animation tick target: exactly 50 ms / 20 Hz.
- Minimum GUI size remains 900×560.
- Redirected CLI output remains plain deterministic text with no ANSI/control sequences.
