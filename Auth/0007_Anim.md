# MRC V0.1 — Animation Authority

## Canonical Spinner
ASCII sequence:

`/ - \\ |`

Each runner owns a visual frame/state, but the UI uses one shared animation timer.

## State Behavior
### OFF
- glyph: frozen `-`
- speed: none
- color: OFF red `#FF5C6C`

### IDLE
- sequence: `/ - \\ |`
- target speed: ~550 ms/frame
- color: IDLE green `#39E58C`

### BUSY
- sequence: `/ - \\ |`
- target speed: ~110 ms/frame
- color: BUSY yellow `#FFD166`

### STARTING
- sequence: `/ - \\ |`
- target speed: ~180 ms/frame
- color: STARTING blue `#4CA7FF`

### STOPPING
- sequence: `/ - \\ |`
- target speed: ~250 ms/frame
- color: STOPPING purple `#B48CFF`

### ERROR
- glyph: frozen `!`
- speed: none
- color: ERROR orange `#FF8A3D`

## Performance Rule
Do not allocate a timer per runner.

Use one shared animation timer that updates visible rows according to their state interval.

## Truthfulness Rule
Animation is purely representational.

The runtime-state engine determines state first; the animation layer only renders that state.

## Visual Intent
The user should be able to perceive runner activity through three simultaneous channels:
- state color;
- motion speed;
- state text.
