# MRC V0.1 — UI & Palette Authority

## UI Model
Use a dense operations-dashboard layout suitable for dozens of runners.

Recommended default window:
- approximately `1180 x 760`;
- resizable;
- minimum approximately `900 x 560`.

## Main Layout
1. title + machine/root identity;
2. state counters;
3. bulk controls;
4. search + filters;
5. compact runner table;
6. bottom refresh/status line.

## Table Columns
Canonical:
- STATUS
- RUNNER NAME
- REPOSITORY
- STATE
- CONTROL

Approximate widths:
- status 55 px;
- runner 250 px;
- repository flexible ~300 px;
- state 100 px;
- control 110 px.

Runner rows target ~42 px high.

Long names ellipsize; never expand row height.

## Stable Ordering
Do not reorder rows by runtime state on refresh.

Default stable sort:
- repository;
- then agent/runner name.

## Search
Instant search across:
- runner name;
- repository;
- runner folder.

## Filters
Canonical filters:
- ALL
- IDLE
- BUSY
- OFF
- ERROR

## Per-Runner Row
Show:
- state-colored left stripe;
- state glyph/spinner;
- runner name;
- repository name;
- state text;
- compact action.

Example:
`┃ /  AgentMesh_MAIN   AgentMesh   IDLE   [ OFF ]`

## Locked Palette
Base:
- background `#0B0F14`
- panel `#111821`
- raised control `#18212B`
- border `#263342`

Text/identity:
- labels/headings `#F4F7FA`
- secondary text `#AAB6C3`
- muted `#667381`
- runner name `#35D9FF`
- repository name `#6BE6FF`
- technical metadata `#74A9D8`
- count accent `#C792EA`

States:
- IDLE `#39E58C`
- BUSY `#FFD166`
- OFF `#FF5C6C`
- ERROR `#FF8A3D`
- STARTING `#4CA7FF`
- STOPPING `#B48CFF`

## Color Discipline
Use semantic color strongly but locally.

Prefer:
- dark button backgrounds;
- semantic border/icon/text;
- stronger semantic tint on hover;
- thin colored row stripe;
- state text in semantic color.

Avoid filling entire rows/buttons with saturated color.

## Hover/Selection
Recommended:
- hover `#16222D`;
- selected row `#17344A` plus cyan outline.

Selection must not replace the row's state color.

## Accessibility
State must be communicated by icon/text/motion as well as color. Color alone is insufficient.
