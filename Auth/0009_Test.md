# MRC V0.1 — Verification & Certification Authority

## Evidence Standard
Do not certify MRC v0.1.0 based only on code review or static inspection.

Material runtime behavior requires direct evidence on Main-PC.

## Minimum Verification Matrix
### Environment / Boundaries
- correct-machine fence works;
- wrong-machine behavior fails closed;
- exact runner-root fence works;
- no runner outside authorized root can be controlled.

### Discovery
- detects all valid immediate-child runners;
- ignores malformed/non-runner directories;
- parses `.runner` identity correctly;
- repository display derivation is correct.

### Runtime State
- OFF detection;
- STARTING transition;
- IDLE detection;
- BUSY detection using same-runner worker association;
- STOPPING transition;
- ERROR behavior.

### Single Control
- individual ON;
- individual IDLE OFF;
- BUSY normal OFF blocked;
- force-stop BUSY requires explicit confirmation;
- closing MRC leaves runners running.

### Bulk Control
- TURN ALL ON starts only OFF runners;
- launch staggering works;
- TURN ALL OFF stops only IDLE runners;
- BUSY runners are skipped and reported.

### UI
- dense table scales to large runner counts;
- stable row order under refresh;
- scroll position remains usable;
- search works;
- filters work;
- counters are correct;
- colors match authority;
- animations match state/speed/color authority;
- no excessive flicker.

### CLI / Installation
- `MRC` works from arbitrary PowerShell location via PATH;
- duplicate GUI prevention works;
- `MRC -v/-version/--version`;
- `MRC -h/-help/--help`;
- `MRC -doctor/--doctor`;
- `MRC -update/--update`.

### Update / Recovery
- valid update path;
- checksum mismatch rejection;
- failed update preserves prior version;
- rollback retention is usable.

## Release Gate
PASS requires:
- all applicable V0.1 requirements verified;
- no unresolved material defect;
- no unverified safety-critical behavior;
- no known boundary violation;
- release artifact hash produced and verified.

If evidence is incomplete, status is HOLD/PARTIAL—not PASS.
